# REQ-NFR-002 — Nessun intermediario

**State:** Active

L'app si collega direttamente ai core scelti dall'utente: non richiede account, non usa server del progetto o di terzi e non invia telemetria o dati di utilizzo. Si verifica controllando che l'app non contenga SDK di analisi e che durante l'uso apra connessioni solo verso le macchine configurate.
