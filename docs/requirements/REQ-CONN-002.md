# REQ-CONN-002 — Core locale nel Linux Terminal

**State:** Active

L'app offre una macchina "Questo dispositivo" che corrisponde al herdr-core in esecuzione nel Linux Terminal di Android. L'app la raggiunge senza che l'utente inserisca host e porta, ne mostra lo stato come per le macchine remote e, se il Linux Terminal non è attivo o non è configurato, spiega all'utente cosa fare.
