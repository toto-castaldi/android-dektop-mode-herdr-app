# REQ-AGT-001 — Sidebar degli agenti

**State:** Active

Una sidebar elenca gli agenti di tutti gli spazi delle macchine collegate, inclusi i worker avviati da altri agenti, con lo stato riportato dal programma: Working (al lavoro), Blocked (in attesa dell'utente), Done (finito mentre l'utente guardava altrove), Idle (fermo, oppure finito e già visto). Gli stati si aggiornano in tempo reale; un agente Done diventa Idle quando l'utente lo guarda. Selezionare un agente con un pane lo porta in primo piano.
