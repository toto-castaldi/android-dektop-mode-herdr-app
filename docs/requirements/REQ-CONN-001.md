# REQ-CONN-001 — Core remoti via SSH

**State:** Active

L'utente può aggiungere una macchina indicando nome, host, porta e utente SSH, e autenticarsi con una chiave generata nell'app o importata, oppure con password. L'app elenca le macchine con il loro stato (connessa, non raggiungibile, autenticazione fallita, core assente o incompatibile), permette di modificarle e rimuoverle, si collega al herdr-core di una macchina e si ricollega quando la connessione cade. L'utente può copiare la chiave pubblica di una chiave generata.
